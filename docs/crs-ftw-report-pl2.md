## CRS go-ftw tests through libstrata

Generated by `make test-crs-ftw` (`strata-rules ftw`, W06-S-01). Each rule of `rules/crs` is compiled alone and its go-ftw tests (`corpus/crs-ftw`) are run through libstrata; a test passes when the rule is (`match`) or is not (`no_match`) in the verdict. A `match` test also passes when Strata's own protocol layer (100000-199999, e.g. a raw NUL byte) blocks the request before the CRS rule is reached: the attack is still caught. Tests of rules at paranoia level 2 and below are counted; a test of a rule that is not imported or not evaluated counts as failed.
