## Defects of the source

| Defect | Now |
| --- | --- |
| The JSON it stored in MinIO was read by nothing: the engine had its own hard-coded ranges | Every bundle carries the latest stored list (`strata-compile --good-bots`, section GOOD_BOTS of W18-R-02) |
| One failing feed aborted the whole sync | A failing feed keeps the crawler's previous ranges, the others update |
| Invalid prefixes skipped silently; no bound on breadth; a "plain" format accepting any text; Cloudflare's CDN ranges as a crawler | A list with one bad, host-bit or too broad (< /8, < /16) prefix is refused whole; only crawlers whose User-Agent claim the engine checks |
| Version = timestamp: every run stored a new object | Version = SHA-256 of the ranges: unchanged lists store nothing; replicas agree |
| Not wired, no metric | `-good-bots-interval`, metrics, alert `StrataGoodBotsStale`, runbook |
