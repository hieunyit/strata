## 1. Mục tiêu và bối cảnh

Bên cạnh SQL Injection (SQLi) và Cross-Site Scripting (XSS), hai họ lỗ hổng tiêm mã nguy hiểm bậc nhất trong ứng dụng web hiện đại là:
1. **Command Injection (CMDi)**: Kẻ tấn công chèn lệnh hệ điều hành thông qua các ký tự phân tách shell (`;`, `|`, `&&`, `||`, backticks, `$()`) nhằm chiếm quyền điều khiển máy chủ web (RCE).
2. **Server-Side Template Injection (SSTI)**: Khai thác cơ chế render template động phía server (Jinja2, Twig, Spring SpEL, OGNL, ERB, Freemarker) để truy cập sandbox context, thực thi reflection và chạy mã tùy ý.

Nhiệm vụ **W17-R-01** bổ sung hai bộ Semantic Detector thuần Rust hiệu năng cao (`detect_cmdi` và `detect_ssti`) vào lõi `libstrata`:
- Hoạt động ở tầng phân tích từ vựng và ngữ pháp (Lexical & Syntactic Analysis), không chỉ dựa vào regex thô.
- Zero-allocation trên luồng request chính, tuân thủ nghiêm ngặt `#![forbid(unsafe_code)]`.
- Tích hợp thành các toán tử quy tắc chính thức: `detect_cmdi`, `detect_ssti` trong IR Schema.
- Hỗ trợ đầy đủ bộ rule CRS Paranoia Level 2 (PL2) nhập tự động qua `strata-import-crs`.

## 2. Chi tiết triển khai

### 2.1. Command Injection Semantic Detector (`engine/src/detectors/injection/cmdi.rs`)
- **Nhận diện toán tử phân tách shell & chuỗi lệnh (Chaining & Separators)**:
  - Phân tích cú pháp `;`, `|`, `&&`, `||`, `&`, `\n`, `\r`.
  - Bỏ qua khoảng trắng và các kỹ thuật né tránh qua biến môi trường shell (`$IFS`, `${IFS}`, `+`).
- **Phát hiện kỹ thuật Command Substitution**:
  - Nhận diện cú pháp thực thi lệnh con lồng nhau: Backticks (`` `command` ``) và `$ (command)`.
- **Nhận diện trình thông dịch và công cụ nguy hiểm (Dangerous Binaries & Utilities)**:
  - Bảng tra cứu trên 60 lệnh nguy hiểm phổ biến trên Unix và Windows: `cat`, `whoami`, `uname`, `id`, `curl`, `wget`, `nc`, `netcat`, `socat`, `ping`, `bash`, `sh`, `powershell`, `cmd.exe`, `python`, `perl`, `ruby`, `chmod`, `rm`, `find`, `grep`, `sleep`...
  - Xử lý kỹ thuật phân tán ký tự bằng dấu nháy (e.g. `c'a't /etc/passwd`).
- **Phát hiện đường dẫn nhạy cảm và mô tả file (Sensitive Paths & Descriptors)**:
  - `/etc/passwd`, `/etc/shadow`, `/dev/tcp/`, `/dev/udp/`, `2>&1`.

### 2.2. Server-Side Template Injection Semantic Detector (`engine/src/detectors/injection/ssti.rs`)
- **Hỗ trợ đa dạng cú pháp Template Engine**:
  - Jinja2 / Twig / Django: `{{ ... }}`
  - Spring SpEL / JSP EL / Freemarker: `${ ... }`
  - Ruby ERB / OGNL / Velocity: `#{ ... }`
  - Thymeleaf: `*{ ... }`
  - ERB / EJS: `<%= ... %>`, `<% ... %>`
- **Nhận diện mẫu Sandbox Escape & Java Reflection**:
  - `__class__`, `__mro__`, `__subclasses__`, `__globals__`, `__builtins__`, `__import__`.
  - `T(java.lang.Runtime)`, `java.lang.System`, `ProcessBuilder`, `getRuntime().exec()`.
  - Các hàm nguy hiểm: `.popen()`, `eval()`, `passthru()`, `config.items`.
  - Thử nghiệm tính toán probe đặc trưng của SSTI: `{{7*7}}`, `${7*7}`, `#{7*7}`.

### 2.3. Tích hợp IR Schema & Evaluator
- `docs/spec/ir.schema.json`: Bổ sung `detect_cmdi` và `detect_ssti` vào enum `operator.type`.
- `engine/src/rules.rs`: Đăng ký `detect_cmdi`, `detect_ssti` vào mảng `OPERATORS`.
- `engine/src/eval.rs`: Tích hợp nhánh đánh giá toán tử trong `condition()`.

- `test_cmdi_detection_suite`: Kiểm thử thành công 100% các vector tấn công thực tế:
  - Chaining: `; cat /etc/passwd`, `| whoami`, `|| whoami`, `&& id`, `& dir`, `127.0.0.1; ping 8.8.8.8`.
  - Substitution: `` `id` ``, `$(uname -a)`.
  - Evasion: `cat$IFS/etc/passwd`, `c'a't /etc/passwd`.
  - Direct execution: `cmd.exe /c dir`, `powershell.exe -enc AAAA`, `/bin/sh -c 'id'`, `sleep 5`.
  - Redirection: `2>&1`, `/dev/tcp/10.0.0.1/4444`.
