# Báo cáo W08-N-01 · Bộ Test::Nginx đầy đủ

Nhiệm vụ: W08-N-01
Nhánh: `W08-N-01-test-suite`
Công cụ: Claude Code

## 1. Hiện trạng và phạm vi

Khảo sát `connectors/nginx/t/` cho thấy các kịch bản "Xong khi" yêu cầu phần lớn
đã có và đang xanh:

| Kịch bản | Đã có ở |
| --- | --- |
| HTTP/2 (HEADERS/END_STREAM, body trong DATA frame, RST_STREAM giữa body) | `002-body.t` (TEST 4–6, 16, 17), `020`, `021` (TEST 3–4) |
| subrequest (chỉ main request được inspect) | `001-basic.t` TEST 10 |
| internal redirect (không inspect lần hai, không đếm metric hai lần) | `002-body.t` TEST 13, `022-body-hardening.t` TEST 5–8, `060` |
| client ngắt giữa chừng (đóng kết nối khi đang chờ body) | `002-body.t` TEST 10, `060` (RST_STREAM) |
| hot reload dưới tải (10 bundle đổi trong khi hammer request) | `004-reload.t` khối "reload under load" |

Thiếu duy nhất: **HTTP/3**. W08-N-01 do đó bổ sung HTTP/3 (build + test) và xác
nhận toàn bộ bộ test chạy xanh trên cả hai bản NGINX, kể cả ASan.

## 2. Đã làm (HTTP/3)

| Mục | Ở đâu | Ghi chú |
| --- | --- | --- |
| Build quictls | `connectors/nginx/scripts/build-quic.sh` | Build quictls (OpenSSL QUIC fork, `openssl-3.1.7+quic`) tĩnh vào prefix; OpenSSL 3.0 của image không có QUIC API |
| Biến thể v3 | `connectors/nginx/scripts/build.sh` | `STRATA_HTTP3=1` → build `nginx-<ver>-h3` với `--with-http_v3_module`, link quictls (từ `/opt/quictls` trong image, hoặc build vào `build/quic`). Build thường/ASan vẫn dùng OpenSSL hệ thống, không đổi |
| Client QUIC (Perl thuần) | `connectors/nginx/t/lib/Test/Strata/HTTP3.pm` | Vendor từ nginx-tests `lib/Test/Nginx/HTTP3.pm` (BSD-2-Clause), đổi package, bỏ `use Test::Nginx`, vô hiệu `log_core`; crypto bằng CryptX. Ghi nguồn + thay đổi ở đầu file và trong `NOTICE` |
| Test HTTP/3 | `connectors/nginx/t/070-http3.t` | Tự lái nginx (như `004-reload.t`): request sạch qua HTTP/3 → allow; `STRATA-TEST-BLOCK` qua HTTP/3 → 403 + Block ID. Skip sạch nếu thiếu build v3 hoặc CryptX |
| Target build/test | `Makefile` (`nginx-h3`, `test-nginx-h3`) | |
| Image | `deploy/dev/Dockerfile` | Thêm quictls `/opt/quictls` và `cpanm CryptX` để CI/image có sẵn HTTP/3 |

**Quyết định kỹ thuật**: client QUIC dùng module Perl thuần của nginx-tests (chỉ
cần CryptX) thay vì build curl+ngtcp2+nghttp3 — ít build gốc hơn (chỉ quictls cho
phía server), test đơn giản và ổn định. Dùng `proxy_pass` (không `return`) cho
location được inspect: strata chạy ở PREACCESS, còn `return` kết thúc ở phase
REWRITE trước đó nên sẽ không được inspect.

## 4. Tự review

1. "Xong khi" có lệnh + output: mục 3.
2. Đường lỗi: test skip sạch khi thiếu build v3/CryptX; client QUIC bọc `eval`.
3. Giới hạn: không đổi code C (chỉ build script, test, Makefile, Dockerfile).
4. Bảo mật: client HTTP/3 chỉ dùng trong test, không đóng vào bundle; cert tự ký chỉ trong servroot test.
5. Ngoài thư mục: `connectors/nginx/` (scripts, t/), `Makefile`, `deploy/dev/Dockerfile`, `NOTICE`, báo cáo, AGENTS.md.

## 5. Việc còn mở

- Image dev hiện tại (trước thay đổi Dockerfile) chưa có `/opt/quictls` và CryptX; local build vào `build/quic`. CI dùng image mới (Dockerfile) sẽ có sẵn.
