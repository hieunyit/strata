# W16-G2-01 — GeoIP preparation accepted in code

Nhiệm vụ: W16-G2-01, sửa và chọn lại phần GeoIP của nguồn w15-w16-enforce-gate-b tại 0dce6de. Nhánh nguồn chỉ có mock reader và schema chưa đủ để nạp/persist MMDB đúng cách. Code acceptance này không phê duyệt Gate B hay thời gian enforce ngoài lab.

Đã chọn và kiểm chứng:

- Reader MMDB thật, byte sở hữu riêng, kiểm loại/cấu trúc/giới hạn và fingerprint cặp City/ASN: #241, [review](w16-mmdb-reader-review.md).
- Cache có giới hạn, canonical IP, copy giá trị, generation/reload không trộn reader cũ/mới, lỗi/cancel giữ bản tốt: #242, [review](w16-geoip-cache-review.md).
- Ingest loại bỏ metadata producer tự khai, gắn dữ liệu server, ghi metric lỗi và giữ sự kiện hợp lệ khi lookup lỗi: #243, [review](w16-geoip-ingest-review.md).
- Schema/migration và native Save/Get/Search thực trên ClickHouse, nullable tọa độ, giữ raw history, bỏ metadata lịch sử không xác minh, FINAL/dedup/context/rule-cost và lỗi stream: #244, [review](w16-geoip-storage-review.md).
- Startup nạp file tùy chọn bằng -geoip-city/-geoip-asn trước khi mở DB/auth/service; gắn enricher vào IngestService trước Fleet Serve. Cả hai mặc định rỗng. Cấu hình sai trả lỗi, không âm thầm dùng reader một phần. [Runbook](../runbook/geoip.md).

Xong khi:

- [x] Event ingest nạp MMDB — loader City/ASN/ASN-only đọc được fixture nhị phân thật, private fast-path và metadata/cancel/error được kiểm thử.
- [x] ClickHouse có country_iso/city/lat/lon/asn/as_org, thêm region/accuracy/version — real DB test cả bảng thiếu cột và bảng Float32 cũ, Save/Get/Search sau enrich, retry chưa merge, null/zero, dữ liệu giả mạo và lỗi driver. Raw cũ không bị xóa.

Kiểm chứng: các review thành phần chứa output fail-trước/pass-sau và full CP -race trên PostgreSQL/ClickHouse thật. Sau bước wiring startup, `go test -race -count=1 -v ./cmd/server` pass (1.467s), cmd lint 0 issues, server build và executable -help pass. Test child process gọi main với file không tồn tại, xác nhận exit 1 và lỗi GeoIP trước DB/auth/service; test loader kiểm actual City/ASN lookup, cặp file thiếu và context bị hủy. Không dùng test này để tuyên bố đã chạy một chuỗi NGINX/agent/CP đầy đủ có GeoIP. Bằng chứng startup được đính kèm.

Giới hạn: fixture tổng hợp không chứng minh độ chính xác/performance của database thương mại, migration bảng lớn hoặc Gate B. Chưa làm worker tự tải hằng tuần/object storage, map, geo/ASN blocking tại node (các nhánh W17+ có review riêng). Không đổi fail mode/budget/body handling hoặc rate-table saturation policy của chủ dự án. Không cập nhật con trỏ tuần/bảng trạng thái nhiệm vụ khác trong AGENTS.

Tự review: asset/path là cấu hình người vận hành, không HTTP input; không tải runtime/network hay ghi license key; buffer/cache/metadata được chặn trên; lỗi được trả về hoặc đếm có chủ đích, không làm mất security event; không đổi proto/C ABI/rule; toàn bộ kiểm chứng trong lab.
