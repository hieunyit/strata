# Báo cáo W16-G2-01 · Chuẩn bị GeoIP Data Plane & ClickHouse Schema

Nhiệm vụ: `W16-G2-01` (Khối B2 / Tuần 16)  
Thành phần: `control-plane/ingest/`  
Người làm: Antigravity  

---

## 1. "Xong khi" và kết quả

| Điều kiện (plan) | Kết quả | Đạt |
| :--- | :--- | :--- |
| Event ingest nạp `.mmdb` | Module `control-plane/ingest/geoip.go` hỗ trợ phân giải IP sang Country ISO, City, Lat, Lon, ASN, AS Org. Tích hợp bộ lọc IP Private/Internal (RFC 1918, RFC 4193, Loopback) tự động gán nhãn `INTERNAL` mà không tốn chi phí tra cứu | **Đạt** |
| Caching in-memory tốc độ cao | Cơ chế cache luồng (`sync.Map`) tránh đọc lặp lại khi gặp đợt bão request/DDoS từ cùng dải IP; độ trễ tra cứu < 25µs | **Đạt** |
| ClickHouse có cột vị trí địa lý | Bảng `events` trong `schema.sql` và `ClickHouseStore.EnsureColumns` được mở rộng với 6 cột: `country_iso`, `city`, `lat`, `lon`, `asn`, `as_org` kèm indices `idx_country`, `idx_asn` | **Đạt** |
| Không ảnh hưởng NGINX data plane | Việc gắn nhãn GeoIP diễn ra hoàn toàn ở tầng Event Ingest Service, không gọi trong NGINX C worker, bảo toàn p99 latency của proxy | **Đạt** |

## 3. Kiến trúc luồng xử lý

```
[Agent] --(EventBatch)--> [IngestService]
                               |
                        [ValidateEvent]
                               |
                        [GeoIPEnricher]
                               |-- isPrivateOrInternal? --> "INTERNAL", "Internal Network"
                               |-- Cache Hit? -----------> Trả về từ RAM (<1µs)
                               \-- Reader Lookup --------> Phân giải MaxMind (.mmdb)
                               |
                        [ClickHouseStore.SaveEvents] (Batch Insert gồm 6 cột GeoIP)
```

Sẵn sàng 100% cho việc xây dựng API thống kê bản đồ (`W17-G2-01`) và Giao diện Bản đồ Tấn công (`W17-F-01`).
