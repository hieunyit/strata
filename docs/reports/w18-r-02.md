# W18-R-02, W18-S-01: good-bot verification in the engine

Source reviewed: `engine/src/bot.rs` and `rules/bots/5000*.yaml` of `a64fb55`
(branch `W18-R-02-good-bot-verification`), `control-plane/botip` of
`4955994`. Rewritten.

## Defects of the source

| Defect | Effect | Now |
| --- | --- | --- |
| Crawler ranges hard-coded in libstrata | Stale the day Google or Bing change them; the control plane's sync job (which stored JSON in MinIO) was never read by any engine | Ranges come with the bundle (section `GOOD_BOTS`), from the control plane's list (W18-G2-02) |
| Cloudflare's ranges listed as a "good bot" | Any request through Cloudflare (any client) became a verified bot | Only crawlers whose User-Agent claim is checked: Googlebot, Bingbot, Applebot |
| Applebot as `17.0.0.0/8` | All of Apple's network verified | Published `applebot.json` ranges only (control plane); prefixes broader than /8 (IPv4) or /16 (IPv6) refused |
| Bundle section kind 11 | Collides with `STAGING` (11) on main | Kind 12, optional; engine checks every invariant of it |
| `X-Strata-Verified-Bot` header rewritten inside rule evaluation | A header value invented by the engine | Two targets: `bot_claim`, `bot_verified` (`true` / `false` / `unknown`) |

## What

- `engine/src/goodbots.rs`: codec `SGB1`, merged sorted ranges, binary
  search, IPv4-mapped IPv6, User-Agent claims; `unknown` when the bundle has
  no ranges for the claimed crawler (never `false`).
- Targets `bot_claim` (code 28), `bot_verified` (29); `strata-compile
  --good-bots <file>` (`{"crawlers": {"googlebot": [...]}}`).
- Rule 500001 (`rules/good-bots/`), core pack (on by default), score 100:
  crawler User-Agent from outside its ranges. Tests run through
  `strata-rules` with documentation-address ranges
  (`rules/testdata/good-bots.json`).
- Not here: the control plane's daily fetch and the deploy feeding it
  (W18-G2-02, next PR). Until then deploys carry no ranges and the rule
  never matches (`unknown`).

## Tests

`engine/src/goodbots.rs` (merge, match, claims, broad prefixes, every
truncation and invariant), `engine/compiler/tests/good_bots.rs` (signed
bundle: spoofed Googlebot/Bingbot blocked, real ranges and IPv4-mapped pass,
Applebot without ranges `unknown`, no section, bad lists refused by the
compiler, damaged section refused by the engine), rule 500001's 8 test
requests through `make test-rules`.
