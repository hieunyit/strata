## 3. Tự review

1. "Xong khi" có lệnh + output: mục 2.
2. Đường lỗi: goroutine agent báo lỗi qua `errc`; main `t.Fatalf` khi có lỗi/timeout; không `t.Fatal` trong goroutine.
3. Giới hạn: `deadline` 10s khớp yêu cầu; chờ kết nối có timeout 30s; buffer `errc` = n.
4. Bảo mật: mTLS thật (mỗi node một chứng chỉ, node id từ SPIFFE URI), không secret trong log.
5. Ngoài thư mục: chỉ `control-plane/fleet/` (test), báo cáo, AGENTS.md.
6. `-race` + golangci-lint sạch.
