# M4 — Internal compiler overlay delegation and snapshot binding

Base PR #187 (`0a8b410`), branch `codex/m4-staging-compiler-adapter`. Adds a compiler-internal effective map, never a public policy API input. Nonempty overlays require validated, enabled enforce-policy delegation and only allowlisted distinct Rule IDs. Unknown/duplicate policies, undelegated IDs, disabled/shadow policies, more than 16 IDs/policy or 4096 overall/policies fail before compiler execution. Empty settings normalize to absence.

The adapter deep-copies/sorts IDs into compiler JSON and the captured replay manifest. Equivalent ID orders hash identically; changing the effective set changes InputDigest. A caller cannot mutate the captured map through its original slice. Normal replay/deploy gates are unchanged: these value checks do not substitute for approval/version/provenance validation. There is no automatic state loader, derivation, worker, outbox or notification in this component.

Validation: own PostgreSQL, `go test -race -count=1 -v ./policy ./replay` with STRATA_TEST_COMPILER pointing to the actual release compiler: **policy 3.011 s, replay 4.625 s**, lint **0 issues** ([full output](evidence/m4-staging-adapter/checks.txt.gz)).
