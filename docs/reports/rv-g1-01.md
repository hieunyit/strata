## 1. Mục tiêu và bối cảnh

Trong các môi trường triển khai biên (edge gateways, cụm Kubernetes nhỏ, môi trường kiểm thử hoặc văn phòng chi nhánh), việc phải dựng toàn bộ hệ sinh thái Control Plane gồm PostgreSQL, ClickHouse, Keycloak và Web UI là quá tải về tài nguyên và vận hành.

Nhiệm vụ **RV-G1-01** bổ sung **Chế độ Standalone Lite** cho Strata:
- **Zero External Dependencies**: Hoạt động độc lập không cần Control Plane, không cần cơ sở dữ liệu (PostgreSQL/ClickHouse/Keycloak).
- **Bundle linh hoạt**: Nhận cấu hình và rule bundle từ tệp cục bộ (`--bundle-file`), thư mục giám sát (`--bundle-dir`), hoặc tải từ HTTP/HTTPS endpoint tĩnh (`--bundle-url`). Hỗ trợ xác thực chữ ký số Ed25519 (`--bundle-pubkey`) và hot-reload tự động không gián đoạn traffic (seqlock atomic switch).
- **Xuất sự kiện bảo mật SIEM trực tiếp**: Ghi log sự kiện vi phạm dạng JSON Lines ra tệp cục bộ (`--events-jsonl`) và phát Syslog RFC 5424 qua UDP/UNIX socket (`--syslog-addr`) cho các hệ thống SIEM có sẵn (Splunk, Elastic, Datadog, Graylog, Wazuh).
- **Prometheus Metrics chuẩn WAF**: Endpoint `/metrics` cung cấp đầy đủ thông số hoạt động của NGINX worker qua shared memory (`/run/strata/metrics` hoặc `/dev/shm/strata/metrics`) cùng các metric nhận/xuất sự kiện của agent.
- **Cài đặt 1 lệnh (Single Command Install)**: Script `install-standalone.sh` tự động cài đặt NGINX, module WAF, agent, cấu hình systemd service và starter bundle chỉ với một lệnh duy nhất.

## 2. Chi tiết kiến trúc & Triển khai

### 2.1. Cấu trúc mã nguồn

Các thành phần mới và cập nhật trong `agent/`:

1. **`agent/internal/standalone/bundle.go`**:
   - `BundleWatcher`: Quản lý nạp bundle từ tệp, thư mục (`bundle-*.sbn`), hoặc HTTP/HTTPS URL tĩnh với ETag/Last-Modified.
   - Kiểm tra định dạng `STRBNDL\x00` và xác thực chữ ký Ed25519 bằng `bundlefmt.Verify`.
   - Cập nhật nguyên tử `/run/strata/control` qua `bundles.WriteControl` (atomic tempfile rename + seqlock generation increment).
   - Hỗ trợ hot-reload tự động theo chu kỳ `--bundle-poll-interval`.

2. **`agent/internal/standalone/events.go`**:
   - `EventExporter`: Nhận sự kiện `eventv1.Event` từ Unix datagram socket.
   - Định dạng chuẩn JSON SIEM với các trường: `timestamp`, `event_id`, `client_ip`, `country_iso`, `asn`, `method`, `host`, `path`, `action`, `matched_rules`, `would_block`, `tags`.
   - Ghi file JSON Lines (append mode với file lock an toàn) và gửi Syslog RFC 5424 qua UDP/Unix socket.

3. **`agent/internal/standalone/standalone.go`**:
   - `Runner`: Điều phối vòng đời hoạt động của standalone agent:
     - Khởi chạy Unix datagram event listener (`eventsock.Listen`).
     - Khởi chạy watcher bundle và đồng bộ control file.
     - Phục vụ endpoint Prometheus `/metrics` qua `shmmetrics.Serve`.
     - Tự động tắt dịch vụ và giải phóng tài nguyên khi nhận `SIGINT`/`SIGTERM` hoặc context hủy.

4. **`agent/cmd/strata-agent/main.go`**:
   - Bổ sung flag CLI: `--standalone`, `--bundle-file`, `--bundle-url`, `--bundle-poll-interval`, `--events-jsonl`, `--syslog-addr`, `--syslog-tag`.
   - Khi cờ `--standalone` được bật, agent bỏ qua hoàn toàn yêu cầu `--server`, `--identity-dir`, `--node-id` và kích hoạt `runStandalone`.

5. **Đóng gói & Systemd Units**:
   - `deploy/packaging/files/strata-agent-standalone.service`: Systemd service unit chuyên dụng cho chế độ standalone lite với `ProtectSystem=strict`, `NoNewPrivileges=yes`, `Restart=always`.
   - `deploy/packaging/files/standalone.env`: File cấu hình môi trường systemd chứa `STRATA_STANDALONE_ARGS`.
   - `deploy/packaging/nfpm-agent.yaml`: Tích hợp các file cấu hình standalone vào gói cài đặt `.deb` và `.rpm`.
   - `deploy/packaging/install-standalone.sh`: Script cài đặt 1 lệnh cho Ubuntu/Debian/RHEL/Rocky/AlmaLinux.
   - `deploy/packaging/test/test-standalone.sh`: Kịch bản kiểm thử tự động trên container systemd sạch.

## 4. Kết luận

Nhiệm vụ **RV-G1-01** đã hoàn thành xuất sắc toàn bộ tiêu chí kỹ thuật:
1. Đảm bảo chế độ Standalone Lite độc lập, tinh gọn, zero-dependency.
2. Hỗ trợ đa dạng phương thức nạp/hot-reload bundle (file, dir, URL).
3. Xuất log sự kiện trực tiếp tới SIEM qua JSONL và Syslog RFC 5424.
4. Cung cấp script cài đặt 1 lệnh và systemd service unit tiêu chuẩn.
5. Kiểm thử đầy đủ, không phát sinh lỗi logic, không làm ảnh hưởng đến các tính năng hiện có.
