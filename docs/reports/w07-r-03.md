# W07-R-03 · Mã hóa sự kiện trong libstrata (strata_tx_event)

Review: L3
Nhánh: `W07-R-03-event-encoding`
SHA: `da6ff3c`
Công cụ: Antigravity

## Đã làm

1. **Protobuf Wire Encoder không phụ thuộc thư viện ngoài** (`engine/src/event.rs`, `engine/src/lib.rs`):
   - Triển khai wire encoder viết tay cho `strata.event.v1.Event` (tag-length-value chuẩn protobuf wire format), không thêm dependency `prost` hay `protobuf`.
   - Giới hạn kích thước gói tin nghiêm ngặt: `MAX_DATAGRAM = 8192` (8 KB). Nếu vượt quá 8 KB, thuật toán cắt giảm có thứ tự: bỏ bớt match từ cuối danh sách, cắt ngắn `path` (tối đa 128 byte), `identity` (32 byte), `request_id` (32 byte) để đảm bảo luôn xuất xưởng datagram `<= 8192` byte.
   - Bảo mật & bảo vệ dữ liệu riêng tư (DLP): Các header nhạy cảm (`Authorization`, `Cookie`, `Proxy-Authorization`) và cookie luôn có snippet rỗng; số CCCD (12 chữ số) và JWT token trong snippet được che bằng ký tự `*` giữ nguyên độ dài (`mask_snippet`).

2. **Metadata & Match Snippet trong libstrata** (`engine/src/detectors/mod.rs`, `engine/src/detectors/protocol/mod.rs`, `engine/src/eval.rs`, `engine/src/tx.rs`):
   - Mở rộng `Violation` mang `layer: &'static str`, `field: String`, `snippet: Vec<u8>`.
   - `eval::evaluate`: Thu thập `MatchDetail` (`field = VAR:key`, `snippet = prepare_snippet(...)`) khi điều kiện khớp. Với request sạch không khớp rule, engine chạy đường dẫn zero-copy, không cấp phát thêm bộ nhớ.
   - `Tx`: Lưu trữ bounded metadata (`node_id` <= 64B, `policy_id` <= 55B, `bundle_version`, `identity` <= 128B, `request_id` <= 64B, `host` <= 255B, `method` <= 16B, `path` <= 1024B, `status`, `layer_scores`, `matches` tối đa 16).
   - Triển khai `Tx::encode_event(&self) -> Option<Vec<u8>>`: Request sạch cho qua không sinh sự kiện (`None`); sinh sự kiện cho request bị chặn (`STR-...`), request shadow đáng lẽ bị chặn (`EVT-...`), lỗi engine/budget (`EVT-...`), hoặc vi phạm tầng response.

3. **C FFI (`engine/ffi/src/ffi.rs` & `strata.h`)**:
   - `strata_tx_new`: Nhận và lưu trữ `identity` và `request_id` từ `strata_conn_t`.
   - `strata_tx_event`:
     - Hỗ trợ chế độ truy vấn kích thước khi `dst == NULL && cap == 0`.
     - Đảm bảo an toàn bộ đệm: chỉ ghi dữ liệu khi `cap >= event.len()`.
     - Cập nhật doc comments của `strata_tx_event`.
     - Đồng bộ file header qua `make header && make check-header` (`engine/ffi/strata.h` và `connectors/nginx/include/strata.h`).

4. **Cross-language Golden Tests** (`engine/tests/event_golden.rs`, `agent/internal/eventsock/eventsock_golden_test.go`, `engine/tests/golden/events/*.bin`):
   - Tạo 5 kịch bản golden binary:
     - `blocked.bin`: Request bị chặn, Block ID `STR-...`, action `ACTION_BLOCK`, status 403, match rule 899001.
     - `shadow.bin`: Request shadow, Event ID `EVT-...`, action `ACTION_LOG`, status 0.
     - `engine_error.bin`: Lỗi engine/budget, Event ID `EVT-...`, action `ACTION_LOG`, status 500.
     - `long_snippet.bin`: Snippet có số CCCD bị che thành `************`.
     - `large_event_truncated.bin`: Sự kiện lớn với nhiều matches được cắt giảm vừa vặn dưới 8192 bytes.
   - Phía Rust: `engine/tests/event_golden.rs` kiểm tra tính xác định và khớp từng byte.
   - Phía Go: `agent/internal/eventsock/eventsock_golden_test.go` dùng `eventsock.Decode` đọc và kiểm chứng từng trường trên cùng fixture `.bin`.

5. **Fuzz Target** (`engine/fuzz/fuzz_targets/event_encode.rs`, `engine/fuzz/Cargo.toml`, `engine/fuzz/run.sh`):
   - Fuzz ngẫu nhiên các cấu trúc `Tx` và `Event` kèm bộ xác thực cú pháp wire format Protobuf đảm bảo mọi luồng byte xuất ra đều hợp lệ và `<= 8192` byte.

## Tự review trước khi báo xong (theo AGENTS.md 6a)

1. **Mọi điều kiện "Xong khi"**: Có đầy đủ lệnh và output thật đính kèm.
2. **Đường lỗi**: Không unwrap() trên dữ liệu không tin cậy; `strata_tx_event` bọc `catch_unwind`; kiểm tra đầy đủ ranh giới buffer.
3. **Giới hạn**: Kích thước gói tin protobuf chặn cứng ở `MAX_DATAGRAM = 8192` byte với thuật toán cắt ngắn an toàn. Metadata (node_id, policy_id, identity, request_id, client_addr, method, host, path) và snippet đều có chặn trên rõ ràng.
4. **Bảo mật**: Các header nhạy cảm (Authorization, Cookie, Proxy-Authorization) được làm rỗng snippet; CCCD (12 chữ số) và JWT token được che mặt nạ bằng `*`.
5. **Phạm vi thay đổi**: Đúng quy định (chỉ sửa `engine/`, `agent/internal/eventsock/`, và cập nhật dòng W07-R-03 trong `AGENTS.md`). Header C chỉ cập nhật doc comments, không đổi chữ ký hàm hay struct ABI.
6. **Chất lượng code**: `cargo fmt` sạch, `cargo clippy -D warnings` không cảnh báo, `go test -race` không data race, AddressSanitizer NGINX module không rò rỉ bộ nhớ.
