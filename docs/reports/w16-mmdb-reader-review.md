# W16-G2-01 — real MMDB reader selection

Source reviewed: `w15-w16-enforce-gate-b`, 0dce6de; the source reader was a mock and did not load MMDB data. This replacement implements the loader/lookup foundation. Ingest wiring, authoritative metadata clearing/enrichment and ClickHouse columns remain subsequent acceptance steps; the full W16 task is not marked Done here.

The reader owns immutable heap-backed City/ASN bytes through maxminddb-golang/v2 2.8.0, pinned in go.mod/go.sum. This avoids closing live mmap readers and prevents truncating/replacing source files from corrupting concurrent lookups. Optional City and ASN sources are regular files bounded to 128 MiB each. Loading checks cancellation, decoder structural verification and supported database types before returning a reader. Its version fingerprints both ordered inputs. Local operator-provided assets are required: structural verification is not publisher authentication and no EULA-protected production database/license key is downloaded.

Only bounded typed metadata is decoded. Invalid UTF-8/control text, incomplete/non-finite/out-of-range coordinates and malformed country values fail explicitly. A missing location remains absent, rather than fabricated coordinates (0,0); a genuine (0,0) result is valid. IPv4-mapped IPv6 is canonicalized. Lookup errors are propagated before checking Found; the explicit error regression failed before that repair.

Synthetic MaxMind test databases are vendored with their upstream commit, hashes, license and provenance. Actual binary lookups verify London/GB/England, latitude/longitude and accuracy radius; the ASN fixture verifies ASN 15169/organization and absent coordinates. Negative tests cover missing/incorrect database types, corrupt and oversized files, canceled loads, invalid input/metadata and reader failure. Concurrent callers mutate returned coordinates without changing others' results; overwriting the source file leaves the active reader usable.

Validation with Go 1.26.9: the 11 reader/cache candidate tests passed under -race (1.841s package) with ingest lint 0 issues. Cache files were then removed from the compilation tree; the full ingest unit/race suite and ingest lint passed again on the isolated reader snapshot (raw log attached). Real ClickHouse tests were not configured for this reader-only step; no ingestion/DB or operational Gate claim follows from these checks.

Self-review: no request-path C/Rust or shared proto changes; bounded decoder inputs/outputs; no secrets/network downloads at runtime; errors are returned; returned scalar pointers have independent ownership; fixture licensing retained. Known limits: supported City/ASN database types only, 128 MiB/file, English city/subdivision names; file I/O/Verify may run until their bounded local operation completes before the next context check. Production dataset accuracy/latency is not established by synthetic fixtures.

Combined-main check after #240: isolated full ingest race suite passed in 5.470s with lint 0 issues. The dependency merge retains every security pin from current main and adds only MMDB v2.8.0 plus its checksums. Raw output is attached as mmdb-reader-current-main.log.gz. Vendored license text is retained in full; handwritten reader/tests are 350 lines.
