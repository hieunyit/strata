# W16 retrospective — operational decisions not accepted by consolidation

The old branch report asserted absolute p99 protection, loss-free upgrades, zero-regression production replay and a mandatory fail-closed route list. Those statements exceed the available evidence. Cooperative budget can leave inspection PARTIAL; finite native/upgrade tests do not prove universal absence of loss or memory defects; replay on a finite corpus does not prove every production request safe.

This integration preserves the owner's budget, fail-mode and oversize decisions. It does not approve route-specific fail-closed changes, expand enforcement, advance the current week or sign Gate B. The tested component/workflow boundaries and remaining operational acceptance are described in [consolidation](branch-consolidation.md), [game-day scope](../runbook/game-day.md) and [Gate B](gate-b.md). The original proposal is retained in Git history for operator review.
