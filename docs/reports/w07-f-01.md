## 1. Đã làm

| Mục | Ở đâu | Ghi chú |
| --- | --- | --- |
| Trang Fleet | `ui/src/pages/FleetPage.tsx` | Node nhóm theo connector group. Mỗi node có: trạng thái kết nối, hostname/id, phiên bản NGINX, phiên bản module, bundle đang chạy, badge trạng thái bundle (DOWNLOADING/VERIFIED/ACTIVE/FAILED), lần cuối thấy, hạn chứng chỉ. Khung rollout: rollout mới nhất còn RUNNING/PAUSED/FAILED, đợt hiện tại trên tổng số đợt, node của từng đợt theo trạng thái (lỗi hiện khi rê chuột), lý do khi FAILED. Làm mới mỗi 3 giây (polling; API không có stream). Chỉ đọc, với mọi vai trò |
| Client | `ui/src/api/client.ts` | `listRollouts`, `getRollout`, qua client sinh từ OpenAPI (`npm run generate:api`; kiểu sinh lại gồm cả API lệnh của W07-G1-01) |
| i18n | `ui/src/i18n/locales/{vi,en}.json` | Trạng thái bundle ("đang dùng") khác trạng thái rollout ("đang triển khai") |
| Phiên bản NGINX/module (cần cho trang) | `ngx_http_strata_events.c`, `agent/internal/shmmetrics`, `agent/internal/control` | API đã có `proxy_version`/`module_version` nhưng agent chưa bao giờ điền. Module ghi `NGINX_VERSION`, phiên bản module và `STRATA_ABI_VERSION` vào header file metrics (offset 32–63, trước đó là dự phòng = 0; `docs/design/control-file.md`). Agent gửi chúng trong `Hello` và mở lại luồng khi chúng đổi (NGINX khởi động sau agent, hoặc được nâng cấp). Không đổi OpenAPI/proto. Phần C: 2.497 dòng |
| Lab | `deploy/lab/compose.yaml` | `-rollout-soak=5s` (canary như production): các đợt hiện rõ trên UI; trước đó rollout lab xong trong khoảng 2 s, giữa hai lượt làm mới |
| Test lab | `ui/tests-lab/lab.spec.ts` | Sự kiện lấy từ request bị NGINX chặn thật (bỏ `strata-emit`); test mới: deploy policy, ghi màn hình ở mỗi lần trạng thái đổi |
