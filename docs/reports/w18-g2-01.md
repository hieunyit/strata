# W18-G2-01: statistics API for the map

Source reviewed: `control-plane/api/{stats,timeline,watch}_handler.go` and
`control-plane/ingest/{geoviews,timeline}.go` of `4955994`…`23480e6`
(W18 branch). Rewritten on the aggregates of W17-G2-01.

## Defects of the source

| Defect | Effect | Now |
| --- | --- | --- |
| SSE "deltas" = rows of the last two intervals of event time | Not a change of what the map shows; events stored late (agent spool, retries) never shown; rows never removed | Rows of the sliding window are read again each interval and compared: changed/new rows and removed keys |
| Every request's context ends after the server's request timeout (10 s, `withMiddleware`) and the server's `WriteTimeout` closes the connection | Streams die after 10 s | Stream route exempt from the request timeout; each write sets its own deadline. Test with 1 s server timeouts; red without either fix |
| No limit on streams, interval from the query (1–10 s), no maximum duration | One user can open unbounded 1 s streams | 32 streams per control plane (503 + Retry-After), interval 2–5 s, 15 minutes per stream |
| Timeline counted actions `monitor`, `pass`, `challenge` from count columns | `monitor` and `challenge` never exist; counts doubled by resent batches | Distinct events by `block`, `shadow`, other (`pass`, `error`) |
| No filter on the stream, none validated elsewhere | — | `policy_id`, `action`, `attack_type`, `country`, `asn`, `limit` validated (400) |
| The browser client opened `EventSource` on `/v1/stats/geo:watch?token=<access token>` | The access token in proxy logs and browser history; main refuses query tokens, so the stream would not even authenticate | Header only (test: query token gives 401); the UI reads the stream with `fetch` (W18-F-01) |

## What

- `GET /v1/stats/geo?groupBy=country|city|asn`, `GET /v1/stats/timeline?step=1m|5m|1h|6h|24h`
  (at most 1,500 buckets), `GET /v1/stats/geo:watch` (SSE). events:read;
  responses say `approximate: true`. OpenAPI and generated UI types.
- `ingest.GeoTimeline`, `ingest.GeoStatsStore`.
- Not here: gRPC `StatsService`/`WatchGeo` (REST like the Overview), the map
  page (W18-F-01).
