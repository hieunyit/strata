## Payload variants against Strata

Generated by `make mutate` (`tools/strata-mutate`, W09-S-02). Each payload of `corpus/attack` is sent in a query parameter and in a urlencoded form field; every one the bundle blocks is mutated and sent again the same way. A variant **bypasses** when its payload is blocked and the variant is not. Lower is better.
